# 전역 로그 전환 — 취소 / 운영 미적용

2026-09-10 운영자 요청에 따라 신규 전역 로그 90일 정책, journal 88일 정리와 Docker journald 전환을 취소했다. 설치 후보와 관련 시험 소스를 제거했으며 재승인을 기다리는 작업이 아니다.

## 과거 검증 기록

- 네트워크·볼륨 없는 합성 컨테이너에서 journald 기록·조회 확인.
- 별도 합성 namespace에서 2초 보관·1초 회전 확인. 제거된 기록은 시험 문자열뿐이다.
- 시험 컨테이너와 시험 서비스·설정 정리.
- 운영 설치 호출은 실행 전에 안전 검토에서 거부됐다. 우회 적용하지 않았다.
- 운영 기본 journal 재시작·정기 삭제 타이머 설치·운영 로그 삭제·컨테이너 드라이버 전환은 하지 않았다.

기존 Docker/Nginx/Tunnel의 회전·용량 제한은 이번에 변경하지 않는다. 따라서 전체 원본 로그의 물리적인 영구 저장을 구현했다고 설명하지 않는다.
